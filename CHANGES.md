## 1.6.2 (2024-07-12)

- Add highest-weight modules: `IsIrreducibleHWModule`, `HighestWeight`,
  `HighestWeightVector`, `DisplayHighestWeight` and
  `IsomorphismOfIrreducibleHWModules`
- Add nilpotent orbit functions `ComponentGroup`, `RichardsonOrbits`,
  `DisplayWeightedDynkinDiagram`, `IsRegular`, `RegularNilpotentOrbit`,
  `IsDistinguished` and `DistinguishedNilpotentOrbits`
- Add `DisplayDynkinDiagram` and `ApplyWeylPermToCartanElement`
- Rewrite `CharacteristicsOfStrata`: it accepts a list of highest weights and
  an optional bilinear form
- `WeylTransversal` with an empty index list returns all Weyl group elements
- Link to the MathJax version of the manual by default
